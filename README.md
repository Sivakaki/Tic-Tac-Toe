# Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML**, **CSS**, and **JavaScript**. The game supports two players, displays the current turn, detects winners, and includes sound effects and animations for a better user experience.

## Features

* Classic 3×3 Tic Tac Toe gameplay
* Turn indicator for players X and O
* Automatic win detection
* Winner announcement
* Winning animation using GIF
* Sound effects for turns and game events
* Reset button to start a new game
* Responsive and clean user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## How to Run

1. Download or clone the repository.

```bash
git clone https://github.com/your-username/tic-tac-toe.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.

## Game Rules

1. Player **X** starts first.
2. Players take turns placing their symbols on the board.
3. The first player to get three symbols in a row, column, or diagonal wins.
4. Click the **RESET** button to start a new game.
